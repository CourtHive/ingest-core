# AGENTS.md

**The guidance for this repository lives in [`CLAUDE.md`](./CLAUDE.md). Read that file.**

This is a pointer, not a second copy. CourtHive keeps repository guidance in `CLAUDE.md` across the
whole ecosystem; this file exists so agents that look for `AGENTS.md` by convention are sent to it
rather than finding nothing. Two documents saying the same thing drift, and then the question is
which one is lying — so there is deliberately only one.

Read `CLAUDE.md` first. It points, in turn, at `../Mentat/` — the ecosystem's orchestration layer,
whose standards override anything repo-local.
